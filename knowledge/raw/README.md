# ProjectWiki raw evidence

This directory is reserved for immutable source evidence that genuinely needs to live inside the
ProjectWiki tree: stable snapshots, external research notes, or small indexes pointing to canonical
repository documents.

Normal Wiki maintenance may add new evidence when explicitly required, but must not rewrite
existing evidence. Prefer canonical tracked sources such as `Tickets/`, `.implementation-reports/`,
`reviews/`, `docs/`, tests, and source code instead of copying them here.

The subdirectories reserve evidence categories for tickets, reports, reviews, tests, external
sources, and decisions. Empty categories remain intentionally empty until real evidence belongs
there.
